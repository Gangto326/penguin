# 🐧❔ Penguin Help

아래 템플릿만 출력한다. 규칙:

- 파일을 만들거나 바꾸지 않고, 다른 스킬을 실행하지 않는다.
- `[언제]` 슬롯은 세션에 로드된 스킬 목록의 해당 description에서
  문장을 그대로 발췌한다 — 기억으로 재작성하지 마라. 줄이려면
  문장 단위로 자르기만 한다.
- 템플릿 밖의 설명·조언을 덧붙이지 마라 — 사용자가 물으면 그때 답한다.
- CLI 터미널 출력이다 — 줄을 짧게, 표는 아래 설정 표 하나만.
- 설정 표의 default가 `penguin-config`의 표와 어긋나면 그쪽이 맞다 —
  이 파일을 고쳐라.

### 🐧 Penguin 도움말

같은 곳을 반복해서 고치게 될 때, 다음 패치 전에 문제를 처음부터 다시
정의하게 하는 재검토 도구 모음.

**흐름**

1. 같은 파일 연속 수정이 `threshold`(기본 4)에 닿으면 hook이 재검토를 권한다 🐧
2. `/penguin` — 패치를 멈추고 재검토 보고서를 낸다
3. 보고서 직후 검증이 자동으로 이어진다 🐧🔍 (`verify_chain` 켜짐 기준)
4. 채택은 사용자 결정 — "패치 유지"면 코드에 `penguin:` 주석이 남는다
5. `/penguin-debt` — 쌓인 주석을 장부로 모아 보여준다

**스킬 4종**

`/penguin` — 재검토
- 언제: [언제]
- 출력: 🐧 보고서 — 한눈 요약 · 상황 설명 · 권고와 대안
- 인자: `/penguin [질문]` — 궁금한 것을 붙이면 보고서가 "질문에 대한
  답"으로 정면 응답 (분석 범위는 안 좁아짐)

`/penguin-verify` — 보고서 검증
- 언제: [언제]
- 출력: 🐧🔍 검증 판정 — 판정 · 변경 사항 · 우선 조치

`/penguin-debt` — 유지 패치 장부
- 언제: [언제]
- 출력: `penguin:` 주석 장부 (읽기 전용)

`/penguin-config` — 설정
- 언제: [언제]
- 출력: 인자 없이 부르면 현재 값이 표시된 선택 화면,
  `/penguin-config <키> <값>`이면 한 줄 변경 보고

**설정** (`/penguin-config`로 확인·변경)

| 키 | 무엇 | default |
|---|---|---|
| `threshold` | 재검토를 권할 연속 수정 횟수 | 4 |
| `verify_budget` | 검증자 조회(tool 호출) 상한 | 15 |
| `verify_chain` | 보고서 직후 자동 검증 | on |
| `debt_comments` | 패치 유지 시 `penguin:` 주석 | on |
