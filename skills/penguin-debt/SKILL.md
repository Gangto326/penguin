# 🐧 Penguin Debt — 유지 결정의 장부

Penguin 재검토가 "패치 유지"로 끝난 지점마다 남겨진 `penguin: <전제/한계>,
<재검토 트리거>` 주석을 하나의 장부로 모아, 미뤄둔 결정이 조용히
영구화되는 것을 막는다.

## 1. 수집

터미널 실행 도구(Bash 등) 또는 파일 검색 도구로 코드베이스의 마커를
수집하라. `node_modules`, `.git`, 빌드 산출물 등은 반드시 제외한다.

**권장 검색 패턴:**

`grep -rnE '(#|//|/\*|<!--|--)[[:space:]]*penguin:' . --exclude-dir={node_modules,.git,dist,build,coverage} --exclude=PENGUIN-DEBT.md`

마커의 정의는 hook 과 같아야 한다 — 공백은 0개 이상이다.

**문서에서 나온 매치는 장부에 넣지 마라.** 스킬 문서·이 스킬의 이전
보고서·주석 서식을 설명하는 마크다운은 실제 부채가 아니다. 코드가 아닌
파일에서 잡힌 매치는 버린다.

(만약 터미널 실행 권한이 없다면, 사용자에게 위 명령어를 직접 실행하고
결과를 붙여넣어 달라고 정중히 요청하라.)

## 2. 분석

수집된 주석에서 다음을 분리하라:

1. **위치:** 파일명 및 줄 번호
2. **부채 내용 (한계/전제):** `penguin:` 바로 뒤부터 트리거 조건 앞까지
3. **재검토 트리거:** 명시된 재검토 조건. 누락됐다면 `no-trigger`로 분류

## 3. 출력

분석 결과를 아래 마크다운 템플릿 양식에 맞춰 출력한다.

### [출력 템플릿 시작]

### 📊 Penguin Debt Report

*(수집된 결과가 없을 경우 아래 문구만 출력하고 종료한다)*
> **"penguin: 빚 없음. 깨끗하다."**

*(결과가 있을 경우 아래 목록 형태로 출력한다)*
- **`<파일경로>:<줄번호>`**
  - **유지한 패치/한계:** <전제/한계 내용>
  - **재검토 조건:** <트리거 내용> *(트리거가 없다면 🚨 `[no-trigger]`
    딱지를 눈에 띄게 붙일 것)*

---
**요약:** 총 표식 `<N>`개, 트리거 누락(부패 위험) `<M>`개.
*(사용자가 원할 경우 이 내용을 `PENGUIN-DEBT.md` 파일로 저장할 수 있음을
안내하라.)*

### [출력 템플릿 끝]

## 4. 경계

이 스킬은 **읽고 보고만 한다** — 요청 없이는 어떤 파일도 만들거나 고치지
않는다. 사용자가 명시적으로 요청한 `PENGUIN-DEBT.md` 저장만 예외다. 코드
리팩터링을 임의로 제안하지 않는다.
